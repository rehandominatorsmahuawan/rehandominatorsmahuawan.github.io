RDM V4 CLOUD PROFILE UPDATE

WHAT IS INCLUDED
- Gallery images persist in Firestore and reload on every device.
- Squad cards open a public Instagram-style player profile.
- Public profile shows DP, player ID, jersey, name, nickname, role, playing details, bio and social links.
- Player can add/edit/delete up to 3 named social links.
- Player password change now asks current password, re-authenticates with Firebase, then changes the real Firebase password.
- Admin can edit any player's official data, jersey, nickname, bio and DP.
- Admin can edit/delete team social cards and set Platform + Display Name + Link + Icon + Image.
- Profile/gallery/social/team changes are stored in Firestore and sync across devices.

IMPORTANT
Images are compressed and stored in Firestore documents in this build, so Firebase Storage billing/setup is NOT required. Keep gallery images reasonably sized; the website compresses them automatically.

INSTALL
1) Back up current ~/rdmweb.
2) Copy/replace the files from this ZIP into ~/rdmweb.
3) Deploy firestore.rules: firebase deploy --only firestore:rules
4) Test locally: cd ~/rdmweb && python -m http.server 8090
5) Open http://localhost:8090/
6) Test Admin, player profile, password change, gallery, social edit/delete, public profile.
7) If correct: git add . && git commit -m "RDM V4 cloud profiles and gallery" && git push

SECURITY
Never upload ~/.rdm-secrets/firebase-admin.json or any service-account JSON to GitHub.
